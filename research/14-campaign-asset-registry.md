# Реестр сочетаний каталогов и ассетов рекламной кампании 2027

**Дата актуализации:** 02.10.2026
**Статус:** рабочий реестр; изображения не генерировались.

## Поля обязательной записи

Для каждого рекламного кадра фиксируются:

| Поле | Назначение |
|---|---|
| `frame_id` | ID кадра рекламной матрицы, не номер каталога |
| `model_id` | Участники кадра |
| `fabric_color_no` | Номер цвета ткани |
| `fabric_color_name` | Название цвета для чтения |
| `print_ribbon` | Цвет/тип риббона печати |
| `font_layout_no` | Номер утверждённого шрифтового макета |
| `drawing_no` | Номер рисунка из каталога 01–81 |
| `personalization` | ФИО, половая надпись, класс, школа, город, год |
| `photo_status` | Статус кадра фотосессии |
| `ad_layout_status` | Статус рекламного оформления |
| `asset_links` | Ссылки только на фактически добавленные файлы |

Номер рекламного кадра нельзя использовать как номер цвета, шрифта или
рисунка. Цвет печати фиксируется отдельно от цвета ткани. Номер рисунка на
изделии не печатается.
