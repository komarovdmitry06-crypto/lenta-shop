# Маркетинговые инструкции проекта

Основные документы:

- [MARKETING_DECISIONS_FINAL.md](MARKETING_DECISIONS_FINAL.md) — утверждённые маркетинговые решения, офферы, CTA, ветки «Ессентуки» и «Россия».
- [LENTA_AI_GENERATION_SPEC_2027_FINAL.md](LENTA_AI_GENERATION_SPEC_2027_FINAL.md) — обязательная спецификация AI-фотосессии 2027, cast bible, master prompt, hard constraints и контроль качества.

## Статус принятия

Оба файла приняты как проектные инструкции. При конфликте с предположениями в исследовании приоритет имеют подтверждённые решения из этих документов и бизнес-база.

## Визуальный пакет

- Официальный логотип: `assets/brand/photocka-logo.svg`.
- Утверждённые модели: `assets/models/reference-sheets/F01_reference.png` … `M03_reference.png`; для кадра с педагогом — `T01_reference.png`.
- Реальные продуктовые и посадочные референсы должны добавляться в `assets/product-references/` и `assets/people-references/`.
- Готовые изображения серии 2027: `assets/campaigns/2027/`.
- Реестр сочетаний каталогов и статусы генерации: `research/14-campaign-asset-registry.md`.
- Утверждённые файлы каталогов находятся в `temp/` и ожидают ручного переноса владельцем в рабочий пакет; соответствия перечислены в `assets/README.md`.
