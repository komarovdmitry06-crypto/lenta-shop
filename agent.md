# Рабочий регламент проекта lenta-shop.ru

## Цель

Подготовить маркетинговый анализ конкурентов для создания лидогенерирующего сайта по услуге проекта.

## Правила ведения работы

- Все исходные запросы, допущения, ход анализа, найденные факты, источники и решения сохраняются в структурированных Markdown-файлах внутри проекта.
- Факты из поисковой выдачи и сайтов конкурентов фиксируются с датой проверки, URL и кратким описанием того, что именно подтверждено.
- Наблюдения, гипотезы и рекомендации маркируются отдельно; выводы не выдаются за подтверждённые факты.
- При анализе поисковой выдачи учитываются регион, язык запроса, тип результата и рекламные/органические позиции.
- Перед рекомендациями по сайту формируются: карта конкурентов, разбор офферов и доверия, структура посадочных страниц, лид-магниты, CTA, SEO-гипотезы и план проверки.
- Маркетинговые инструкции проекта находятся в `marketing/MARKETING_DECISIONS_FINAL.md` и `marketing/LENTA_AI_GENERATION_SPEC_2027_FINAL.md`; считать их обязательными при подготовке маркетинга и визуалов.
- Официальный логотип использовать только из `assets/brand/photocka-logo.svg`; AI не должен генерировать логотип.
- Утверждённые модели использовать только через reference sheets в `assets/models/reference-sheets/`; лица не реконструировать по памяти. `T01` — отдельная взрослая модель педагога и не входит в основной выпускной каст.
- Локальную ветку Ессентуков и дистанционную ветку России не смешивать в одном рекламном тезисе.
- Для локальной ветки базовым путём считать дистанционное обсуждение и согласование заказа; шоурум в Ессентуках показывать только как дополнительную возможность для сомневающихся в цвете или материале, а не как обязательный этап заказа.
- Не обещать актуальные фото или видео оттенка как точную замену физическому образцу: из-за блеска сатина цвет сложно достоверно передать съёмкой. Если оттенок принципиален, рекомендовать сомневающимся посмотреть актуальный физический образец в шоуруме.
- Для сторис использовать базовую серию из 3 изображений подряд (рабочий диапазон 2–4), стартово 2 серии в неделю; последовательность: предложение → кастомизация → утверждённый CTA «Напишите — рассчитаем», «Покажем варианты →» или «Закажите у нас →».
- Для рекламных визуалов соблюдать двухэтапный конвейер: сначала кадр фотосессии, затем отдельное оформление сторис на основе утверждённого кадра.
- В каждом рекламном кадре сохранять полный блок из трёх преимуществ; один выбранный акцент может быть визуально главным, но не заменяет остальные преимущества.

## Рабочая структура

```text
research/
  00_brief.md                 # бриф, запрос пользователя, допущения и вопросы
  01_search-results.md        # зафиксированная поисковая выдача
  02_competitors/             # отдельный файл на каждого конкурента
  03_comparative-analysis.md  # сравнительная таблица и маркетинговые выводы
  04_leadgen-site-strategy.md # стратегия собственного лидогенерирующего сайта
  05_sources.md               # реестр источников и дата проверки
  06_open-questions.md        # что требуется уточнить или проверить
  11-order-economics.md       # статистика заказов и экономика материалов
  12-site-sales-and-advertising-model.md # сайт, Директ и первичный лид
assets/
  brand/                       # официальный логотип
  models/reference-sheets/     # F01–F03, M01–M03
  product-references/          # реальные продуктовые фото
  people-references/           # реальные фото посадки
  campaigns/2027/              # рекламные визуалы серии 2027
```
